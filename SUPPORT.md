# Getting Help

| I want to… | Go to |
|---|---|
| Ask a question or share an idea | **Discussions** in the relevant repository |
| Report a software or firmware bug | **Issues → Bug report** |
| Report a mechanical or electrical problem | **Issues → Hardware issue** |
| Request a feature | **Issues → Feature request** |
| Report a vulnerability or safety hazard | [SECURITY.md](SECURITY.md) (privately, never in public) |
| Contact the team about anything else | **[hello@your-domain]** |

## Before you ask

- Search existing issues and discussions; your question may already have an answer.
- Read the repository's README and documentation.
- Include versions, hardware revision, logs and the steps you took. The more context, the faster we can help.

Maintainers help on a best-effort basis. Please be patient and keep the conversation in public threads so others can benefit from the answers.
